# Анализ поисковых запросов в Яндекс Картинках (Test Task)

Решение тестового задания по анализу пользовательского поведения в сервисе Яндекс Картинки. Проект демонстрирует навыки работы с данными, применения SQL внутри Python-среды и умение интерпретировать результаты для бизнеса.

##  Цель проекта
Проверить гипотезу о различии интересов пользователей, использующих поиск по картинкам на мобильных устройствах (touch) и компьютерах (desktop), на основе выборки запросов за 3 недели.

##  Стек технологий
*   **Язык:** Python 3.14.3
*   **Библиотеки:** 
    *   `Pandas` — обработка и очистка данных.
    *   `Matplotlib`, `Seaborn` — визуализация временных рядов и распределений.
    *   `Pandasql (SQL)` — выполнение аналитических выборок с использованием синтаксиса SQL.
    *   `Jupyter Notebook` — среда для проведения исследования.

##  Основные этапы исследования
1.  **Exploratory Data Analysis (EDA):** Определение временных рамок и структуры данных.
2.  **SQL-выборки:** Расчет специфических запросов (например, упоминаемость бренда "ютуб") с использованием SQL-синтаксиса.
3.  **Сравнительный анализ:** Выявление топ-10 запросов для каждой платформы.
4.  **Анализ временных рядов:** Изучение часовой активности пользователей и объяснение паттернов поведения.
5.  **Контрастный анализ:** Выделение тематик, характерных исключительно для одной из платформ.

##  Ключевые инсайты
*   **Гипотеза подтверждена:** Пользователи Desktop-версии чаще решают «рациональные» и рабочие задачи (поиск таблиц, календарей, учебных материалов).
*   **Мобильный трафик (Touch):** Носит более «эмоциональный» и ситуативный характер (поздравления, погода, быстрый поиск развлекательного контента).
*   **Временные паттерны:** Десктопный трафик имеет ярко выраженный профиль «рабочего дня», в то время как мобильный трафик распределен более равномерно с пиками в утреннее и вечернее время.

##  Как запустить проект
1.  Клонируйте репозиторий:
    ```bash
    git clone https://github.com/ваш-логин/yandex-images-search-analysis.git
    ```
2.  Установите зависимости:
    ```bash
    pip install pandas matplotlib seaborn pandasql notebook
    ```
3.  Запустите Jupyter Notebook:
    ```bash
    jupyter notebook yandex_analysis.ipynb
    ```
